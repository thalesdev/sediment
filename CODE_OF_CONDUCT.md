# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Read it there. In short:

- Be respectful and welcoming. Disagree with ideas, not with people.
- No harassment, insults, discrimination or personal attacks, in any form.
- Do not publish the private information of others.
- Give and accept feedback with care. Assume good faith.

## Enforcement

The maintainer can edit, hide or remove comments, issues and contributions that
break this code, and can ban a person who breaks it again after a warning.

To report a problem, use the
[private report](https://github.com/thalesdev/sediment/security/advisories/new)
of this repository and say that it is about conduct, or write to the maintainer
through the contact on their GitHub profile. Reports are handled in private.
